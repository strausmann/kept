Kept läuft als Home-Assistant-App: Kept und seine eigene Datenbank in einer App, auf Home Assistant
OS. Kein Docker Compose, keine Passwörter, die du dir ausdenken musst, und die Sicherungen von Home
Assistant schließen es ein.

## Home-Assistant-App oder normale Installation?

Dasselbe Kept, dieselbe Version, dieselben Funktionen: Gegenstände, Orte, Raumplan und Graph,
Scannen, Etiketten, KI, MCP, Importe, Paperless, mehrere Personen.

| | Home-Assistant-App | [Compose](/de/install/compose/) oder [Kubernetes](/de/install/kubernetes/) |
|---|---|---|
| Geöffnet über | die Seitenleiste von Home Assistant, und die eigene Adresse von Kept (Port 8080) | die eigene Adresse von Kept |
| Installieren, aktualisieren | App-Store von Home Assistant | `docker compose`, `helm` |
| Erstes Konto | Ein Home-Assistant-Admin richtet es ohne Code ein | Der Einrichtungscode aus dem Log von Kept |
| Einstellungen | Der Reiter **Configuration** der App | `.env` oder die Werte des Charts |
| Offline, Handy-App installieren, Push | Die eigene Adresse von Kept über https; nicht in der Seitenleiste | Über https |
| Passkeys, OIDC, Google | Die eigene Adresse von Kept (https für Passkeys; https und ein öffentlicher Domainname für Google) | Die Adresse von Kept |
| Sicherungen | Die Sicherungen von Home Assistant; außer Haus über seine [Sicherungsorte](https://www.home-assistant.io/common-tasks/general/backups/) | Die eigenen nächtlichen Sicherungen von Kept: restic in einen Ordner, nach S3 oder per SFTP |
| Fotos und Dateien | In den Daten der App | Auf der Festplatte, oder S3 |

- **Die App:** Du betreibst schon Home Assistant OS.
- **Compose oder Kubernetes:** alles andere; oder Fotos und Dateien auf S3; oder die eigenen
  Sicherungen von Kept außer Haus.

## Installieren

<HomeAssistantButton />

1. **Settings → Apps → Install app → ⋮ → Repositories**, füge
   `https://github.com/keptinventory/kept` hinzu (oder nutze den Knopf oben).
2. Suche **Kept**, dann **Install**, dann **Start**.
3. **Open Web UI**. Kept öffnet sich in Home Assistant, und auch in der Seitenleiste.

| Du brauchst | |
|---|---|
| Home Assistant OS | Apps brauchen den Supervisor: nicht Home Assistant Container oder Core. Supervisor 2026.10.4 oder neuer |
| `aarch64` oder `amd64` | Einen Raspberry Pi 4 oder 5 mit 64 Bit, einen Mini-PC, eine VM |
| 4 GB Arbeitsspeicher | 2 GB reichen bei wenigen anderen Apps; Kept mit seiner Datenbank braucht im Leerlauf etwa 250–320 MB |

## Erster Start

- Ein **Administrator** von Home Assistant, der Kept aus Home Assistant öffnet, richtet es ohne Code
  ein (Supervisor 2026.10.4 oder neuer; davor wird der Code gebraucht).
- Alle anderen geben den Einrichtungscode aus dem Reiter **Log** der App ein
  (`KEPT SETUP CODE: XXX-XXX`).
- Kept hat eigene Konten. Man meldet sich einmal bei Kept an, auch innerhalb von Home Assistant;
  Mitglieder des Haushalts müssen keine Home-Assistant-Administratoren sein, um es aus der
  Seitenleiste zu nutzen.

## Die Adresse von Kept

Innerhalb von Home Assistant öffnet sich Kept aus der Seitenleiste. Handys, gedruckte
QR-Etiketten, Links in Mails, die Integration und KI-Apps brauchen eine Adresse, die auch außerhalb
einer Home-Assistant-Sitzung funktioniert. Deshalb stellt die App Kept zusätzlich auf **Port 8080**
bereit. Der Reiter **Log** nennt sie, zum Beispiel `Kept is at http://homeassistant.local:8080`.

| Option | Was |
|---|---|
| Kept's address | Setzen, wenn `homeassistant.local` in deinem Netz nicht aufgelöst wird oder der Port geändert wurde. `http(s)://host[:port]`, ohne Pfad. |
| https on Kept's port | Stellt den Port über https bereit, mit dem Zertifikat von Home Assistant aus `/ssl` (von den Apps DuckDNS oder Let's Encrypt). Starte die App neu, nachdem das Zertifikat erneuert wurde. |
| HSTS | Standardmäßig `on`. `off`, wenn Home Assistant selbst oder eine andere App unter diesem Hostnamen über einfaches http läuft: Das HSTS von Kept gilt für den Hostnamen auf jedem Port, 8123 eingeschlossen ([HSTS](/de/install/reverse-proxy/#hsts)). |
| Sign-in length over http | Leer: 12 Stunden, nicht verlängert. Sonst die Tage, die eine Anmeldung über einfaches http hält, 1 bis 30, verlängert, solange sie benutzt wird. Ohne Wirkung, wenn https eingeschaltet ist; den Preis beschreibt [Im eigenen Netz bleiben](/de/install/home-network/#im-eigenen-netz-bleiben). |
| Extra addresses | Weitere Adressen, unter denen dieses Kept antwortet, durch Kommas getrennt, etwa `http://192.0.2.20:8080`. Leer: eine. Kommt zu der von Home Assistant hinzu, ersetzt sie nie ([mehr als eine Adresse](/de/install/home-network/#mehr-als-eine-adresse)). |
| Outgoing mail | Eine `smtps://`-URL: Anmeldelinks, Einladungen und Erinnerungen per Mail. |
| OIDC, Google | Anmeldung über deinen eigenen Identitätsanbieter oder über Google. Leer: aus. |
| Apprise server | Der Apprise-API-Server für Benachrichtigungskanäle über Apprise. Leer: keiner. |
| Sign-up | `true` oder `false` hält die Registrierung fest offen oder geschlossen; ohne Wert entscheidet ein Admin. |
| Upload limit (MB) | 1 bis 2048; Standard 25. |

Der Anbieter schickt die Leute zurück an die eigene Adresse von Kept, nie an Home Assistant.
Einzutragende Weiterleitungs-URL: `<Adresse von Kept>/api/v1/auth/callback/oidc` für OIDC,
`<Adresse von Kept>/api/v1/auth/callback/google` für Google. Der Reiter **Log** gibt sie aus,
sobald die Anmeldung eingerichtet ist. Innerhalb von Home Assistant öffnet **Anmelden mit …** die
Adresse von Kept in einem neuen Tab.

Google lehnt eine Weiterleitungs-URL über http, mit einem `.local`-Namen oder mit einer IP-Adresse
ab ([Googles Regeln](https://developers.google.com/identity/protocols/oauth2/web-server#uri-validation)):
Setze **Kept's address** auf https mit einem öffentlichen Domainnamen, etwa einem DuckDNS-Namen mit
**https on Kept's port**. Der Reiter **Log** warnt, wenn es so nicht geht.

Schaltest du Port 8080 ab (Configuration → Network), bleibt nur die Seitenleiste: Etiketten und die
Handy-App öffnen sich dann nicht.

## Was https braucht

| | Einfaches http | https |
|---|---|---|
| Gegenstände, Orte, Suche, Etiketten, Fotos aus einer Datei | ja | ja |
| Persönliche Tokens (die Integration), geheime Werte anzeigen, Exporte | nein | ja |
| Passkeys, die Kamera, die Handy-App installieren, Push | nein | ja |

Innerhalb von Home Assistant gilt Kept nur dann als https, wenn Home Assistant selbst über https
läuft. Ein Proxy vor Home Assistant, der TLS beendet, muss `X-Forwarded-Proto: https` senden, sonst
sieht Kept einfaches http. Passkeys gehören zur eigenen Adresse von Kept: Melde dich dort mit einem
an. Mehr unter [Kept im Heimnetz](/de/install/home-network/).

## Sicherungen und Updates

- **Sicherungen:** Die Sicherungen von Home Assistant schließen Kept ein: die Datenbank als Dump,
  Fotos, Dateien und die Schlüssel von Kept. Lass die Verschlüsselung der Sicherungen in Home
  Assistant eingeschaltet. Das Wiederherstellen der Sicherung holt Kept zurück; der erste Start
  danach dauert etwas länger.
- **Eine Sicherung, während Kept gestoppt ist,** enthält den Dump, den Kept beim letzten sauberen
  Stopp geschrieben hat: Home Assistant fragt nur eine laufende App nach einem frischen. Starte Kept
  nach einem Absturz, bevor du sicherst.
- **Die eigenen Sicherungen von Kept** gibt es in der App nicht: Sie brauchen die Anmeldung des
  Datenbankeigentümers, die die App vom laufenden Server fernhält. Admin → Sicherungen sagt das und
  verlinkt auf die Sicherungen von Home Assistant.
- **Außer Haus:** Füge in den Sicherungseinstellungen von Home Assistant eine Netzwerkfreigabe oder
  einen Cloud-Speicherort hinzu
  ([Sicherungen von Home Assistant](https://www.home-assistant.io/common-tasks/general/backups/)).
- **Updates:** Die Version der App ist die von Kept. Ein Update behält die Daten von Kept und
  aktualisiert seine Datenbank beim Start. Schalte im Update-Dialog von Home Assistant **Keep backup
  of the last version** ein: Der eigene Snapshot von Kept vor einem Update ist in der App aus.

## Die Integration

Diese App betreibt Kept; eine separate Integration holt es in Home Assistant hinein. Schalte **https
on Kept's port** ein, bevor du sie verbindest
([die App und die Integration](/de/users/home-assistant/#the-app-and-the-integration)).

[Die Kept-Integration](/de/users/home-assistant/) bringt, was fällig ist, nach Home Assistant. Gib
ihr die Adresse von Kept und ein persönliches Token, das über https angelegt wurde. Die Einrichtung
ohne Token, direkt aus der App, kommt mit einer späteren Version.
